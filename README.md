## The book resource

Each book has six attributes:

| Attribute | Type | Rules |
|---|---|---|
| `id` | string | Generated by the server (`b1`, `b2`, …). Clients may not send it. |
| `title` | string | Required, 1–100 characters |
| `author` | string | Required, 2–60 characters, letters, spaces, `.` `'` `-` only |
| `genre` | string | Required, 2–30 characters |
| `year` | number | Required, whole number from 1450 to the current year |
| `price` | number | Required, greater than 0 (ZAR) |

The API starts with three books: `b1` Clean Code, `b2` Long Walk to Freedom and `b3` Things Fall Apart.

## How to run

```bash
cd secure-mern-app/api
npm install
copy .env.example .env      # Windows (use cp on macOS/Linux)
npm start
```

The server runs on `http://localhost:4000`.

## Routes / endpoints tested in Postman

| # | Method | URL | Purpose | Expected status |
|---|---|---|---|---|
| 1 | GET | `http://localhost:4000` | Root route – welcome message and list of endpoints | 200 OK |
| 2 | GET | `http://localhost:4000/health` | Health route – server status, uptime and time | 200 OK |
| 3 | GET | `http://localhost:4000/api/books` | Fetch all books | 200 OK |
| 4 | GET | `http://localhost:4000/api/books/b1` | Fetch one book by its id | 200 OK |
| 5 | POST | `http://localhost:4000/api/books` | Add a new book (done five times, see below) | 201 Created |
| 6 | GET | `http://localhost:4000/api/books` | Fetch all books again – 8 books after the five adds | 200 OK |

### Input validation checks (all `POST http://localhost:4000/api/books`)

| # | Test | Request body | Expected result |
|---|---|---|---|
| 1 | Empty body | `{}` | 400 – every field is required |
| 2 | Missing title | body without `title` | 400 – title is required |
| 3 | Invalid author | `"author": "J4mes 123"` | 400 – author may contain only letters, spaces, `.` `'` `-` |
| 4 | Genre too short | `"genre": "A"` | 400 – genre must be 2–30 characters |
| 5 | Year in the future | `"year": 3000` | 400 – year must be between 1450 and the current year |
| 6 | Year and price as text | `"year": "2018", "price": "350"` | 400 – year and price must be numbers |
| 7 | Negative price | `"price": -50` | 400 – price must be greater than 0 |
| 8 | Title too long | `title` of 101 characters | 400 – title must be 100 characters or fewer |
| 9 | Client sends an id | `"id": "b1"` | 400 – unknown field `id` not allowed |
| 10 | Malformed JSON | `{ "title": "Broken JSON", ` | 400 – invalid JSON (central error handler) |

### Error handler and CORS checks

| # | Method | URL | Extra | Expected result |
|---|---|---|---|---|
| 1 | GET | `http://localhost:4000/api/books/b99` | – | 404 – book not found |
| 2 | GET | `http://localhost:4000/api/unknown` | – | 404 – route not found |
